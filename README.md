# Naveen Milk Sales Calculator

A mobile-friendly, single-file milk sales calculator.

## Deploy with GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish publishing.

The site URL should be: https://naveentech1999.github.io/Naveen-Milk-Sales-App/

## Notes
- Sales are stored in local browser storage on the device/browser where you enter them.
- Download the daily CSV invoice regularly for backup.
- This version is a single HTML file and does not need an assets folder.
